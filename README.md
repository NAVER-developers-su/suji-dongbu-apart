# 수지동부아파트 리모델링 대출 계산기

동·층·호만 고르면 내 세대의 **이주비 대출**과 **추가사업비(사업촉진비) 대출** 한도, 그리고
만기까지의 이자를 계산해 주는 정적 웹페이지입니다.

금리와 이자 계산 방식이 아직 조합에서 확정되지 않았기 때문에, 하나의 값을 못박는 대신
**가정을 바꿔가며 경우별로 비교**할 수 있게 만들었습니다.

> 참고용 추정치입니다. 실제 대출 조건은 조합과 금융기관의 안내를 따릅니다.

## 쓰는 법

1. 동 / 층 / 호를 고릅니다
2. 매수 시점을 고릅니다 (이주비 LTV가 달라집니다)
3. 두 대출에 받고 싶은 금액을 넣습니다 — 한도를 넘길 수 없습니다
4. `상세 설정`에서 금리·기간·이자 방식을 바꿔가며 비교합니다

결과는 `한도` / `이자` / `금리 민감도` 세 탭으로 나뉘어 있습니다.

## 데이터

`분담금.json` — 2026년 정기총회 책자 303~319쪽에서 판독한 **612세대 전량**
(동 101~106 × 층 1~17 × 호 1~6).

세대마다 종전·종후 감정평가액(삼창·대화 두 법인 값과 평균), 권리가액, 분담금, 전용·공급면적,
타입을 담고 있습니다.

판독 정확도는 표 안에 있는 산술 항등식으로 612행 전량 검증했습니다.

| 검증 항목 | 결과 |
|---|---|
| 종전평균 = (삼창 + 대화) ÷ 2 | 612/612 일치 |
| 종후평균 = (삼창 + 대화) ÷ 2 | 612/612 일치 |
| 권리가액 = 종전평균 × 비례율 | 실효 비례율 109.1000~109.1002%로 수렴 |
| 분담금 = 종후평균 − 권리가액 | 612/612 일치 |
| 동+호수 중복 / 층 누락 | 0건 |

별도로 촬영한 317쪽 사진과 교차 대조해 일치를 확인했습니다.

## 계산 근거

### 한도 — 「추가사업비 대여 신청 최종 신청서」

```
대출가능 총액       = 종후 감정평가액 × LTV 90%
이주비 대출 한도     = 종전 감정평가액 × LTV 60%   (2025.10.15 이후 매수는 40%)
잔여한도            = 대출가능 총액 − 이주비 신청액 − 분담금
                      (이주비 미신청 시 기존 주담대 실제 잔액을 대신 차감)
추가사업비 원금한도   = 잔여한도 ÷ (1 + 연이율 ÷ 12 × 개월수)      ← 십만원 절사
```

마지막 줄이 핵심입니다. 추가사업비는 **원금과 이자를 합한 금액을 신청**하는 구조라, 한도라는
버킷 안에 원금과 만기까지의 이자가 함께 들어갑니다. 그래서 실제로 손에 쥐는 원금은 한도를
이자계수로 나눈 값입니다.

매수 시점별 이주비 LTV는 조합 「추가사업비 대여 2차 수요 조사서」 기준입니다.

| 매수 시점 | 이주비 한도 |
|---|---|
| 2025.06.27 이전 | 종전자산 평가액의 60% 이내 |
| 2025.06.28 ~ 10.14 | 별도 상담 필요 |
| 2025.10.15 이후 | 종전자산 평가액의 40% 이내 |

### 이자 — 조합 공식 계산시트

```
추가사업비 이자 = 원금 × 5.28% ÷ 12 × 55개월 = 원금 × 24.2%     ← 십만원 올림
```

순수 월할 단리입니다. 날짜나 일수 개념이 없고 기산일도 없습니다.

금리 5.28% = CD(91일물) 2.92% + 가산 2.22% + 취급수수료 0.14%이며, **취급수수료는 이미
금리 안에 포함**되어 별도로 더하지 않습니다. "3개월 변동금리"는 CD 재설정 주기이지 복리
주기가 아닙니다.

만기 55개월, 만기일시상환, 중도상환 불가.

### 이자의 이자에 대하여

조합이 구두로 안내한 "1억당 대출금 이자 2,672만원 + 이자의 이자 57만원"은 공식 계산시트에서
재현되지 않습니다. 시트대로면 1억당 2,420만원이고 이자의 이자 항목 자체가 없습니다.

두 숫자는 동시에 성립할 수 없습니다. 복리주기(1·3·6·12개월) × 기간(1~120개월) × 금리
(2~10%)를 전수 대입해도 두 값을 함께 만족하는 조합이 없습니다. 이자의이자/원금이자 비율
2.13%는 20~30개월짜리 대출의 비율인데, 2,672만원은 55개월 이상에서 나오는 금액이라 서로
모순입니다.

그래서 특정 값을 못박지 않고 **이자 계산 방식을 고르는 방식**으로 만들었습니다.

| 방식 | 이자 계수 |
|---|---|
| 단리 | `r ÷ 12 × n` |
| 3개월 복리 | `(1 + r ÷ 4)^(n ÷ 3) − 1` |
| 월복리 | `(1 + r ÷ 12)^n − 1` |

"이자의 이자"는 별도 항이 아니라 **복리 총액에서 단리분을 뺀 나머지**로 정의했습니다. 단리를
고르면 자동으로 0이 되므로 조합 시트와 숫자가 정확히 일치합니다.

조합 확답이 오면 기본값을 그에 맞게 바꾸면 됩니다.

## 구성

```
index.html        구조
styles.css        디자인 토큰과 컴포넌트 (모바일 퍼스트, 흰색 단일 테마)
app.js            계산과 렌더링
분담금.json        612세대 데이터
build_preview.py  전부 인라인한 단일 파일 preview.html 생성
```

빌드 도구도, 프레임워크도, 외부 의존성도 없습니다. 그대로 GitHub Pages에 올라갑니다.

## 로컬에서 보기

`app.js`가 `분담금.json`을 `fetch`하기 때문에 파일을 직접 열면(`file://`) 동작하지 않습니다.
간단한 서버를 띄우세요.

```bash
python3 -m http.server 8000
# http://localhost:8000
```

한 파일로 묶어서 보고 싶다면:

```bash
python3 build_preview.py   # preview.html 생성 (데이터·CSS·JS 전부 인라인)
```
